# Automate — Keyboard Shortcuts

## Global

| Shortcut | Action |
|----------|--------|
| `⌘K` / `Ctrl+K` | Open Command Palette |
| `[` | Toggle sidebar collapse |
| `Escape` | Close modal / Command Palette |
| `?` | Show this shortcuts reference |

## Navigation

| Shortcut | Destination |
|----------|-------------|
| `G D` | Go to Dashboard |
| `G R` | Go to Runs |
| `G T` | Go to Tests |
| `G A` | Go to Analytics |
| `G C` | Go to Config |
| `G S` | Go to Settings |

## Run Detail (`/runs/:id`)

| Shortcut | Action |
|----------|--------|
| `⌥T` / `Alt+T` | Toggle terminal panel |
| `⌥A` / `Alt+A` | Abort current run |
| `Space` | Scroll terminal to bottom |
| `⌘F` / `Ctrl+F` | Search in terminal |
| `⌘C` (in terminal) | Copy selected text |

## Test Explorer (`/tests`)

| Shortcut | Action |
|----------|--------|
| `↑` / `↓` | Move selection up / down |
| `Enter` | Open selected test detail |
| `F` | Cycle group-by (File → Suite → Status → Worker) |
| `/` | Focus search filter |
| `Escape` | Clear filter |

## Config Editor (`/config`)

| Shortcut | Action |
|----------|--------|
| `⌘S` / `Ctrl+S` | Save config |
| `⌘Z` / `Ctrl+Z` | Undo (Monaco editor) |
| `⌘⇧Z` / `Ctrl+Shift+Z` | Redo (Monaco editor) |
| `⌘⇧P` / `Ctrl+Shift+P` | Monaco command palette |

## Analytics (`/analytics`)

| Shortcut | Action |
|----------|--------|
| `1` – `6` | Jump to chart card by index |
| `R` | Refresh all charts |

## Runs List (`/runs`)

| Shortcut | Action |
|----------|--------|
| `N` | New run (open trigger dialog) |
| `⌘Enter` / `Ctrl+Enter` | Confirm run trigger |
| `Delete` | Delete selected run (with confirmation) |

---

> Shortcuts only fire when focus is **not** inside a text input, textarea, or contenteditable.
