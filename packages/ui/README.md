# @automate/ui

The shared Tailwind 4 component library, design tokens (`src/tokens/theme.css`) and the icon set. Colour is always a token; a literal hex fails the build.

```bash
pnpm --filter @automate/ui test
```

Part of the [Automate](https://github.com/Sergey-Bar/AutoMate) monorepo; see the root README for the whole picture.
