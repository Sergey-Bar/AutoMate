# @automate/reporter

Producer adapters that read Playwright JSON, JUnit XML, k6 summaries, OWASP ZAP XML and legacy uploads into one canonical run result, including retries as `flaky`.

```bash
pnpm --filter @automate/reporter test
```

Part of the [Automate](https://github.com/Sergey-Bar/AutoMate) monorepo; see the root README for the whole picture.
