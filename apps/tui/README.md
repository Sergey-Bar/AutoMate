# @automate/tui

A read-only terminal client. It reads one command name from argv, sends it to the API, and prints the answer. It has no shell, no stdin parser and no child processes, by design.

```bash
pnpm --filter @automate/tui test
```

Part of the [Automate](https://github.com/Sergey-Bar/AutoMate) monorepo; see the root README for the whole picture.
