distribution-model change, not a release step, and is out of scope. If wanted, it needs its

**Do not substitute `pnpm verify:local`.** It sets `AUTOMATE_HOST_SCANNERS=unavailable`, which
makes `security:static` exit 0 *without scanning* — a green that means nothing.

Already verified, so do not pre-debug: the `oci` job needs no scanner install step

and the job's absent `pnpm build` is not a defect. The residual risk is only that the job has
never run — so if it fails, read the failure as possibly a real defect in the workflow.
